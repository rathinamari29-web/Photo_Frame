# 📸 Photo Frame – Frame Your Memories

A simple and interactive web application built using **Python Flask, HTML, CSS, and JavaScript**. This project allows users to upload their favourite photos, choose from different photo frames, and preview their framed memories.

## ✨ Features

- Upload photos from your device.
- Choose from multiple photo frames.
- Preview uploaded photos instantly.
- Change frames dynamically.
- Simple and user-friendly interface.
- Live image preview using JavaScript.

| Technology | Purpose |

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/rathinamari29-web/Photo_Frame.git
```

### 2. Navigate to the project folder

```bash
cd Photo_Frame
```

### 3. Install Flask

```bash
pip install flask
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

Visit:

```text
http://127.0.0.1:5000/
```

## 🚀 How to Use

1. Open the application in your browser.
2. Upload an image from your computer.
3. Select your favourite photo frame.
4. Preview your photo with the selected frame.
5. Choose another frame to update the preview.
